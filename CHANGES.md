# Changes

## 0.1.0 (2026-11-17)

First alpha: the rules engine, the pace model, eight conditions, learner and teacher-copy actions, sequences,
exit conditions, sending limits, send window, dry runs, privacy provider.

## 0.2.0 (2026-11-17)

Course pages: rules list, rule editor with 7 recipes, upcoming reminders, learners and learner timeline with
extensions, log, pacing settings and pause. Snooze or stop link in reminders (essential rules excepted). Course
backup and restore of rules and pacing.

## 0.3.0 (2026-11-17)

Hooks for other plugins to apply site rules to courses and add courses to the scan; site rules shown on the course
Rules tab; step actions in the editor come from the registry, so actions from other plugins can be chosen.
